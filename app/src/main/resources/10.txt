    2. Dodefinovanie zadania

Synchronizácia
Úloha požaduje aby bolo zachované poradie vykonávania procesov. Teda aby bolo poradie vykonávania procesov rovnaké na všetkých systémoch. Problém predbiehania procesov bude nutné riešiť pomocou niektorých z prostriedkov medzi-procesorovej komunikácie.

Makefile
Tiež je potrebné vytvoriť súbor Makefile. Je nutné dodržať názvy zdrojových textov a vytvorených spustiteľných programov. Zdrojové texty a Makefile je potrebné odovzdať na príslušný server.

Testovanie
Testovanie je realizované na serveri. Testuje sa úspešnosť vytvorenia programov a následne po spustení programov je vyhodnotený výsledok v súbore serv2.txt.
    3. Popis relevantných štruktúr, algoritmov, dátových typov a konštánt

Prostriedok pre komunikáciu medzi procesmi. Ide o sériovú komunikáciu.

Zdieľaná pamäť
Prostriedok pre komunikáciu medzi procesmi. Je to segment zdieľanej pamäte vo FAP. Jednotlivé procesy si môžu svoje LAP k tejto pamäti pripájať alebo odpájať.

V programe sa vieme ku tejto pamäti dostať pomocou celočíselnej hodnoty – identifikátoru.
struct shmid_ds {
struct ipc_perm shm_perm;    /* Ownership and permissions */
size_t          shm_segsz;   /* Size of segment (bytes) */
time_t          shm_atime;   /* Last attach time */
time_t          shm_dtime;   /* Last detach time */
time_t          shm_ctime;   /* Last change time */
pid_t           shm_cpid;    /* PID of creator */
pid_t           shm_lpid;    /* PID of last shmat(2)/shmdt(2) */
shmatt_t        shm_nattch;  /* No. of current attaches */
};

    4. Analýza problematiky

Práca so súbormi
Budeme potrebovať zapisovať a čítať zo vstupných súborov p1.txt a p2.txt do výstupného súboru serv2.txt ako aj do nepomenovaných rúr SM1, SM2.
Potrebujeme dostať identifikátor na súbory pomocou služby jadra open, pre rúry to bude služba jadra pipe. Pre zápis je dostupná služba jadra write, pre čítanie službu jadra read. Pre ukončenie s prácou so súbormi slúži služba jadra close.
Signály
Proces proc_pr pošle signál procesu proc_p1 alebo procesu proc_2. Na tieto signály potrebujeme patrične reagovať. Bude sa nám hodiť aj posielanie signálu, napríklad pri ukončení všetkých nami vytvorených procesov.
Na nastavenie ako ma reagovať proces na signál slúži služba jadra signal. Pomocou nej môžeme nastaviť ktorý podprogram sa ma vykonať podľa konkrétneho signálu. Pre zasielanie signálov slúži služba kill.
Rúry
Pre komunikáciu medzi procesmi proc_p1,proc_p2 – proc_pr a medzi procesmi proc_pr – proc_t potrebujeme vytvoriť prostriedok na medzi-procesorovú komunikáciu – rúry.
Služba jadra pipe nám vyplní pole deskriptorov. S rúrou vieme pracovať ako so súbormi, teda môžeme volať služby jadra ako write alebo read.
Zdieľaná pamäť
Budeme potrebovať vytvoriť zdieľane pamäte medzi procesmi. Ku prvej zdieľanej pamäti pripojíme procesy proc_t a proc_s, ku druhej zdieľanej pamäti pripojíme procesy proc_s a proc_d.
Pre vytvorenie zdieľanej pamäte nám poslúži služba jadra shmget. Na pripojenie ku zdieľanej pamäti slúži služba jadra shmat, na odpojenie zas služba shmdt.
Semafor
Budeme potrebovať synchronizáciu medzi procesmi. Zdieľaná pamäť nemá sama o sebe synchronizačne prostriedky. Vytvoríme preto sady semaforov, S1 pre synchronizáciu procesov proc_t a proc_s, sadu semaforov S2 pre synchronizáciu procesov proc_s a proc_d.
Pre vytvorenie sady semaforov slúži služba jadra semget. Pre narábanie, najme zvyšovanie a znižovanie hodnôt o 1, slúži služba semop. Služba semctl slúži na počiatočne nastavenie, alebo zistenie hodnoty semaforu ale aj na zmazanie tejto sady semaforov.
Sieťová komunikácia
V rámci za budeme potrebovať vyriešiť medzi-sieťovú komunikáciu procesov proc_d, proc_serv1 a proc_serv2.
Pre vytvorenie socketu použijeme službu jadra socket, službou bind priradíme socket IP adresu a port. Pomocou služby listen na strane servera vytvoríme pamäť pre uchovavnie požiadaviek na pripojenie.
Volanie procesov
Proces zadanie bude musieť okrem vyhradenia pamäte zavolať aj ďalšie procesy. 
Pre vytváranie procesov nám poslúžia služby jadra fork a execve.

    5. Popis navrhovaného riešenia

Vyhradenie IPC prostriedkov
Pomocou služby jadra shmget, sme vyhradili zdieľanú pamäť (SM1, SM2) a získali k identifikátory. Pre vytvorenie jedinečného kľúča na odovzdanie ako argumenta pre službu shmget sme použili službu ftok. Pri každom generovaní nového kľúča sme odovzdali službe ftok iný parameter proj_id, parameter cesty sme nastavili na adresár v ktorom sa nachádza program. Pomocou vhodnej kombinácie parametru shmflg sme zavolali službu so zámerom vytvoriť zdieľanú pamäť ak ešte neexistovala. Pomocou služby jadra sme vytvorili nepomenovane rúry (R1, R2). Podobne sme postupovali pri vyhradení pamäte dvojice semaforov. Na to sme použili službu semget. 
Inicializácia IPC prostriedkov
Pomocou služby jadra semctl sme nastavili hodnoty semaforov na požadované hodnoty. 
Príprava argumentov pre dcérske procesy
Pomocou funkcii strcpy a sprintf sme si uložili požadované argumenty identifikátory (port1, port2, rúry...) v podobe reťazcov. 
Volanie dcérskych procesov
Pre zavolanie dcérskych procesov sme použili službu jadra fork a execve. Pri volaní execve sme poskytli  procesom aj potrebne pole argumentov.
Signály
V programe zadanie sme si vytvorili handler – funkciu ktorá zastaví všetky vytvorené procesy. Tato funkcia je zaregistrovaná pomocou služby signal, a tato funkcia vola službu kill na všetky procesy vytvorené hlavným procesom.
Synchronizácia
Tá bola realizovaná pomocou semaforových sád. V podprocesoch na svoje vzájomne synchronizovanie sme vytvorili pomocne funkcie semaphore_v, semaphore_p. Ak jeden podproces dokončil svoju prácu, zápis, čítanie alebo odoslanie zmenil hodnotu semaforu a signalizoval druhému procesu že môže vykonať svoju činnosť.
Networking
Proces_d získa adresu serveru pomocou gethostbyname a pošle žiadosť o pripojenie pomocou connect. Následne proces vstúpi do nekonečného cyklu a pomocou komunikácie s procesom proc_s cez rúru získa dáta. Tieto dáta následne odošle pomocou služby send. Tento proces sa sprava ako client.
Proces proc_serv2 naopak funguje ako server, pomocou recvfrom a write zapíše do koncového súboru serv2.txt nadobudnuté dáta.


    6. Záver a zhodnotenie

Riešenie je správne, požadovaný výsledok bol naplnený. Správnosť nášho riešenia kontrolovali aj automatické testy na vzdialenom serveri .
Rozdelenie úlohy na menšie časti, ktoré je možne riešiť súbežne je spravidla dobrý spôsob ako urýchliť spracovanie úlohy. Keďže úloha nebola komplexná čo do časovej náročnosti, časová závislosti finálneho riešenia je lineárna, závisí od dĺžky jednotlivých správ na prečítanie a od ich počtu vzhľadom na daný okamih.
Čo sa týka pamäte, použili sme duplikovanie 2 deskriptorov. Jedná sa mierne navýšenie pamäťovej ceny. Nejde o nič zasadne, ale je možne že, existuje spôsob pre mierne efektívnejšie riešenie.
Problém sa vyskytol aj pri vytváraní sad semaforov, identifikátor by mal začínaj najmenej od 2, no na niektorých systémoch sa vyskytla pre semaforovú sadu aj hodnota identifikátora 0 alebo 1.

8.	Systémová príručka – príručka pre programátora

int semaphore_p(int sem_id);
Tato funkcia slúži na zníženie hodnoty druhého semaforu zo sady, semafor sa zablokuje. Hodnota sem_flg je mastavena na hodnotu SEM_UNDO.
V prípade úspešného vykonania vráti 1, inač vracia hodnotu 0; 
int semaphore_v(int sem_id);
Tato funkcia slúži na zvýšenie hodnoty, druhého semaforu zo sady, semafor sa odblokuje. Hodnota sem_flg je nastavená na hodnotu SEM_UNDO.
V prípade úspešného vykonania vráti 1, inač vracia hodnotu 0; 
void killProcesses(int in);
Slúži na zastavenie všetkých procesov ktoré boli vytvorené procesom zadanie. Funkcia nemá návratovú hodnotu.
void handler(int sig);
Funkcia precitá jeden riadok zo vstupného textového súboru podľa zadania. Do príslušnej pipe podľa zadania zapíše tento načítaný riadok. Je doležíte aby tato funkcia nezbehla paralelné. Funkcia nemá návratovú hodnotu.

proc_p1.cpp
#include <stdio.h>
#include <unistd.h>
#include <stdlib.h>
#include <fcntl.h>
#include <string.h>
#include <signal.h>
#include <sys/wait.h>
#include <sys/types.h>

int pipe_fd, fd;

void handler(int sig){

    char word[151];
    char c;
    int i = 0;

    while(read(fd, &c, 1) > 0){
        word[i++] = c;
        word[i]='\0'; 
        if(c =='\n') break;  
    }  
     
    write(pipe_fd,word,strlen(word));
}

int main(int argc, char const *argv[])
{   
    signal(SIGUSR1,handler);
    if (argc != 2) {
        perror("2 arguments");
        exit(EXIT_FAILURE);
    }

    fd = open("p1.txt",O_RDONLY);
    if(fd == -1){
        perror("p1 text");
        exit(EXIT_FAILURE);
    }

    pipe_fd = atoi(argv[1]);

    printf("p1\n");
    kill(getppid(),SIGUSR1);

    while(1){
        sleep(2);
    }   

    return 0;
}

{
    if(argc != 2){
        perror("2 arguments");
        exit(EXIT_FAILURE);
    }

    kill(getppid(), SIGUSR1);

    int sockfd, portno, output, count = 0;
    char buffer[151];
    struct sockaddr_in serv_addr;
    struct sockaddr_in client_addr;
    socklen_t client_addr_len = sizeof(client_addr);

    // vytvorenie socketu
    sockfd = socket(PF_INET, SOCK_DGRAM, 0);
    if (sockfd < 0){
        perror("ERROR opening socket");
        exit(EXIT_FAILURE);
    }
        
    bzero((char *)&serv_addr, sizeof(serv_addr));
    portno = atoi(argv[1]);
    serv_addr.sin_family = AF_INET;
    serv_addr.sin_addr.s_addr = INADDR_ANY;
    serv_addr.sin_port = htons(portno);

    if (bind(sockfd, (struct sockaddr *)&serv_addr, sizeof(serv_addr)) < 0){
        perror("ERROR on binding");
        exit(EXIT_FAILURE);
    }
           
    output = open("serv2.txt", O_CREAT|O_WRONLY, 0666);

    printf("UDP server uspesne vytvoreny na porte %d.\n", portno);
    
    while (1)
    {
        bzero(buffer, 151);

        if (recvfrom(sockfd, buffer, 151, 0, (struct sockaddr*)&client_addr, &client_addr_len) < 0){
            perror("ERROR reading from socket");
            exit(EXIT_FAILURE);
        }

        if(write(output,&buffer,strlen(buffer)) < 0){
            perror("ERROR writing");
            exit(EXIT_FAILURE);
        }
            
        if(write(output,"\n",1) < 0){
            perror("ERROR writing");
            exit(EXIT_FAILURE);
        }

        count++;
        if(count == 10) break;
    }

    kill(getppid(), SIGUSR2);
    return 0;
}
