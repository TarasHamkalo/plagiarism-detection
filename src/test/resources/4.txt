Tento dokument popisuje úlohu Inter-Process Communication (IPC) a odporúčaný kód na vyriešenie tohto problému. Dokument obsahuje definíciu úlohy, popis štruktúry, algoritmus, dátové typy, analýzu problému, navrhované riešenie, popis, záver a vyhodnotenie, ako aj prílohu obsahujúcu príručku programátora, používateľskú príručku a zdrojový kód. Schéma

— procesy vyznačené zvýrazneným okrajom sú programy, ktoré budú pri kontrole zadania dodané. Teda treba vypracovať iba programy P1, P2, T, D a Serv2.


PROCES Zadanie (vypracovaný študentom, nie je zakreslený v diagrame)
Spúšťanie
zadanie 
Funkcia
Parametre hlavného programu sú čísla portov pre servery Serv1 (TCP) a Serv2 (UDP). Tieto čísla je potrebné týmto procesom odovzdať. Program Zadanie nech vyhradí všetky zdroje (pre medziprocesovú komunikáciu) a nech spustí všetky procesy. Všetky procesy nech sú realizované ako samostatné programy.

PROCES Pr
Spúšťanie
proc_pr 
Funkcia
Proces Pr pošle signál SIGUSR1 svojmu hlavnému procesu (Zadanie) na signalizáciu, že je pripravený. Proces Pr si údaje bude žiadať:
    • Ak pošle signál (SIGUSR1) procesu P1, nech tento proces (P1) zapíše slovo prečítané zo súboru p1.txt.
    • To isté platí aj pre proces P2 a p2.txt. Teda, ak proces Pr pošle signál (SIGUSR1) procesu P2 nech do rúry R1 zapíše slovo proces P2 zo súboru p2.txt.
Proces Pr k slovu prijatému z rúry R1 pridá svoju značku a zapíše nové slovo do rúry R2.
PROCES S 
Spúšťanie
proc_s 
Funkcia
Proces S pošle signál SIGUSR1 svojmu hlavnému procesu (Zadanie) na signalizáciu, že je (proces S) pripravený. Proces S príjme slovo zo zdieľanej pamäte SM1 so synchronizáciou semaforom S1 (pozri časť o semaforoch v časti „Popis komunikácie“), pripíše k nemu svoju značku a zapíše ho do zdieľanej pamäte SM2 so synchronizáciou semaforom S2.
PROCES Serv1
Spúšťanie
proc_serv1 <číslo portu 1> <číslo portu 2>
Funkcia
Proces Serv1 vytvorí TCP server (na porte <číslo portu 1>), ktorý bude prijímať TCP pakety. Server prijaté slová označí svojou značkou a pošle ich ďalej na UDP server (port <číslo portu 2>). Čísla portov 1 a 2 sú argumenty hlavného procesu (pozri kapitolu „PROCES Zadanie“). Proces Serv1 pošle signál SIGUSR1 svojmu hlavnému procesu (Zadanie) na signalizáciu, že je (proces Serv1) pripravený. TCP aj UDP server nech vytvorený na lokálnom počítači, teda na počítači „127.0.0.1“ (pozor, nie „localhost“!).

PROCES D
proc_d 
Funkcia
Proces D prijíma slová cez zdieľanú pamäť SM2 a semafor sem2 a posiela ich do procesu Serv1 cez TCP server. Proces odošle signál SIGUSR1 svojmu rodičovskému procesu (Enter), aby naznačil, že proces je pripravený. TCP server je vytvorený lokálne, t.j. na počítači "127.0.0.1".

PROCES P1, P2
proc_p1 <id rury 1 na zapis>
proc_p2 <id rury 1 na zapis>
Funkcia
Procesy P1 a P2 čakajú na signál SIGUSR1 z procesu Pr a ktorýkoľvek proces prijme signál, pošle slovo do pipeline_1.

PROCES T
proc_t 
Funkcia
Proces T používa semafor, aby zabránil procesu S čítať dáta zo zdieľanej pamäte 1, kým sa slovo v potrubí 2 neprečíta a nezapíše do zdieľanej pamäte 1.

Popis relevantných štruktúr, algoritmov, dátových typov, konštánt 
Dátové štruktúry

Rúry
      Rúry sú jednosmernou komunikačnou metódou. Dáta zapísané na jednom konci potrubia sa čítajú na druhom konci potrubia (jednosmerný tok údajov). Potrubia sa vytvárajú volaním jadra pipeline(). Keď je vytvorený kanál, systém zaberá 2 miesta v otvorenej tabuľke súborov procesu. Každý potomok zdedí takto vytvorenú fajku.

Semafory
     Semafor je pasívny synchronizačný nástroj. Vo svojej najjednoduchšej forme je semafor pamäťové miesto, ku ktorému môže pristupovať viacero procesov. Semafor je celočíselná systémová "premenná" s povolenými hodnotami <0,max (celé číslo)>, ktorá obmedzuje prístup k zdieľaným zdrojom operačného systému Unix. Je to počítadlo, ktoré sa zvyšuje alebo znižuje prevádzkou na ňom. Nikdy to však neklesne pod nulu. Synchronizácia je zabezpečená dvomi neprerušiteľnými operáciami P a V (buď vykonaná raz alebo vôbec).
Zdieľaná pamäť
 	Zdieľaná pamäť je segment pamäte (špeciálna sada rámcov vo FAP alebo vymenených na disku). Segment je mapovaný do adresných priestorov dvoch alebo viacerých procesov. Proces mapovania pamäťového segmentu do priestoru adries procesu je nasledujúci. Proces vytvorí segment zdieľanej pamäte v FAP a objaví sa v LAP procesu. Iné procesy potom môžu „pripojiť“ túto časť zdieľanej pamäte v FAP k svojim vlastným LAP. To znamená, že rovnaký segment operačnej pamäte počítača sa objaví v LAP viacerých procesov.
Synchronizácie
Semafor S1
 	Vytvorte dvojicu semaforov pre semafor S1. Proces T je riadený semaforom S1[0] a proces S je riadený semaforom S1[1], kde nastavenie semaforu S1[0] (to znamená, že je nastavený na 1) znamená, že proces T môže zapisovať do zdieľanej pamäte (SM1 ). Nastavenie semaforu S1[1] znamená, že proces S môže čítať dáta zo zdieľanej pamäte (SM1).
 
Semafor S2
	Pre semafor S2 sa vytvorí dvojica semaforov. Proces S sa riadi podľa semaforu S2[0] a proces D sa riadi podľa semaforu S2[1]. Pričom nastavený semafor S2[0] (rozumie sa nastavený na hodnotu 1) znamená, že proces S môže zapisovať do zdieľanej pamäte (SM2). Nastavený semafor S2[1] znamená, že proces D môže zo zdieľanej pamäte (SM2) údaje čítať.

        perror("write to r1");

void read_line(int pipe, char* dest) {
    int n = 0;
    char buffer;
    bool isEndOfLine = false;

    while (!isEndOfLine) {
        if (read(pipe, &buffer, 1) == -1) {
            perror("read pipe r2");
            exit(EXIT_FAILURE);
        }

        insertAt(dest, buffer, n);
        if (buffer != '\n')
            n++;
        else
            isEndOfLine = true;
    }
}

void insertAt(char* line, char s, int index) {
    if (s != '\n'){
        line[index] = s;
        line[index + 1] = '\0';
    }
}

bool sem_operation(int op, int num){
    struct sembuf semaphore;
    semaphore.sem_op = op;
    semaphore.sem_num = num;
    semaphore.sem_flg = SEM_UNDO;

    if (semop(sem, &semaphore, 1) == -1) {
        return false;
    }
    return true;
}

    inet_pton(AF_INET, "127.0.0.1", &server_addr.sin_addr.s_addr);

        exit(EXIT_FAILURE);
    }

    kill(getppid(), SIGUSR1);

    filefd = open("serv2.txt", O_CREAT | O_WRONLY | O_TRUNC, 0777);
    if (filefd == -1){
        perror("serv2: file open chyba! ");
        exit(EXIT_FAILURE);
    }

    printf("serv2: primam data\n");
    // bzero(&buffer, 256);
    size_cl_addr = sizeof(client_addr);
    while (itter_file > 0){
        if (recvfrom(sockfd, buffer, 256, 0, (struct sockaddr *)&client_addr, &size_cl_addr) < 0){
